# 文件系统为内容真相源（自动保存 + 监视驱动）

连续编译"无需保存"的实现路径：前端防抖 500ms 后自动保存全部脏文件，后端 notify 监视磁盘变化作为**唯一编译触发源**。否决了"编辑器内存经 IPC 直传后端"：大文档传输开销、latexmk 终究要磁盘路径、外部编辑器修改无法触发。副作用：外部修改同样触发编译；前端需过滤自保存文件避免重载跳动（§5.5）；脏缓冲与磁盘短暂不一致（冲突对话框后置）。

- **状态**：已接受
- **备选方案**：内存真相 + IPC 直传（否决，理由如上）；混合双语义（否决：两套保存路径，复杂度不成比例）
- **影响**：watch 是唯一触发入口；保存语义统一——自动保存/保存触发/外部修改走同一路径；自动保存术语见 CONTEXT.md
